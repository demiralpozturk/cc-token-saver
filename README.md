# cc-token-saver

> Unofficial community plugin for Claude Code. Not affiliated with or endorsed by Anthropic.

Hooks and a status line that cut wasted tokens in Claude Code sessions and show what a session costs.
Work in progress; see [docs/how-it-works.md](docs/how-it-works.md) for what the hook API allows.
